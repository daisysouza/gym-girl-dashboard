# Gym Girl Advance 💖

Gamified fitness dashboard inspired by cozy games and RPG systems.

## Features

- XP system
- Daily missions
- Achievement system
- Streak tracking
- Theme switcher
- Local persistence
- Responsive layout
- Feature-based architecture

## Tech Stack

- React
- Vite
- CSS Modules
- LocalStorage
- Feature-Based Architecture
